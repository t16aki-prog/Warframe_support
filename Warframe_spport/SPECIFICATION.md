# TennoNavi (Warframe Support Tool) 仕様書

## 1. アプリケーション概要

### 1.1 名称・目的
* **アプリケーション名**: TennoNavi (Warframe Support Tool)
* **概要**: TPSアクションゲーム『Warframe』プレイヤー向けの非公式・高機能ファンメイド総合支援Webアプリケーション。
* **主要目的**:
  * オープンワールド環境（地球、エイドロンの草原、オーブ峡谷、カンビオン隔離庫等）のリアルタイム監視
  * Void亀裂・ウィークリー特別任務（突入、アルコン討伐戦、鋼の道のり等）の即時把握
  * 欲しいアイテムやPrimeパーツからドロップレリック・ミッションを検索する逆引き辞書
  * 通常4人マルチおよび特殊ルール「氷河の縛り（The Icebind）」に対応したリアルタイム分隊募集ロビー
  * Google Gemini API および ローカルLLM（Ollama）を統合したAIセファロン（オーディス）による攻略・ビルド相談

### 1.2 セーフティ設計・免責事項
* 公開API（`warframestat.us` 等）および静的データ、ユーザー入力のみを利用。
* ゲーム本体（`Warframe.x64.exe`）のメモリ読み書き、DLLインジェクション、マクロ自動操作等の規約違反行為は一切行わない完全外部支援設計。

## 2. システム構成・技術スタック

### 2.1 フロントエンド
* **フレームワーク**: React 19.x + Vite 8.x
* **言語**: TypeScript 5.x
* **スタイリング**: Vanilla CSS + カスタムユーティリティ（ダーク・オロキンテーマ、サイバーパンク/近未来UI）
* **アイコン**: `lucide-react`
* **リアルタイム通信**: `socket.io-client`

### 2.2 バックエンド
* **ランタイム**: Node.js (v18以上推奨)
* **フレームワーク**: Express 5.x
* **リアルタイム通信**: `socket.io` (分隊ロビー、リアルタイムチャット)
* **外部AI統合**: `@google/generative-ai` (Gemini 1.5/2.0), ローカルOllama API連携
* **プロセス管理**: `concurrently` (フロントエンドとバックエンドの同時起動)
* **セキュリティ・防御**: インメモリレートリミッター（120 req/min/IP）、オリジン制限CORS設定

## 4. 機能要件・詳細仕様

### 4.1 ダッシュボード (Dashboard)
1. **オープンワールド環境サイクル**:
   * 地球（昼/夜: 4時間周期）
   * エイドロンの草原（昼100分/夜50分）
   * オーブ峡谷（温暖/寒冷: 20分周期）
   * カンビオン隔離庫（Fass/Vome）
   * 次の切り替わりまでの残りカウントダウンをミリ秒精度で算出・プログレスバー表示。
2. **Voidの亀裂 (Fissures)**:
   * リソ (Lith), メソ (Meso), ネオ (Neo), アクシス (Axi), レクイエム (Requiem), オムニア (Omnia)
   * 通常ミッションと鋼の道のり (Steel Path) のフィルタリング機能。
3. **アラート＆侵略 (Alerts & Invasions)**:
   * 開催中の特別報酬、勢力進捗率（グリニア vs コーパス等）の可視化。

### 4.2 レリック逆引き＆募集文生成 (Relic Generator)
1. **逆引きマトリクス**:
   * パーツ名（例: `Saryn Prime Chassis`）を入力すると、収録されている全レリック、入手先ミッション、現在の保管庫（Vault）状況を表示。
2. **リクルートチャット自動生成**:
   * レリック名、精錬度（無傷/輝く）、周回数を選択すると、ゲーム内チャット用の定型文（例: `[Axi S9 Relic] Rad 4B4 1/4`）を1クリックでクリップボードへコピー可能。

### 4.3 分隊マッチングロビー (Multiplayer)
1. **通常マルチロビー (4人枠)**:
   * ホストによる部屋作成（目的: 亀裂ラン、素材収集、レリック開放、鋼の道のり周回等）。
   * パスワード設定機能、参加者一覧のリアルタイム同期（Socket.IO）。
2. **氷河の縛り (The Icebind) 専用ロビー (6人動的枠)**:
   * 公式特殊縛りルール「氷河の縛り」に準拠。
   * Warframe重複の自動検知・警告システム。
   * 特殊役割・装備制約のチェックリスト機能。

### 4.4 セファロン・オーディス AI (Cephalon Ordis)
1. **ハイブリッドLLM対応**:
   * Google Gemini API (クライアント側またはサーバー側)
   * ローカルLLM (Ollama: `qwen2.5:7b` 等)
2. **音声対話 (Web Speech API)**:
   * ブラウザ内蔵の音声合成を利用し、オーディス風の口調で読み上げ。
3. **ビルド相談・クイックファクト**:
   * Warframe名や武器名を指定した初心者向け・エンドコンテンツ向けビルドのアドバイス。

## 5. 通信仕様・APIエンドポイント

| メソッド | パス | 説明 |
| :--- | :--- | :--- |
| `GET` | `/api/status` | バックエンド健全性確認 |
| `GET` | `/api/worldstate` | `warframestat.us` のキャッシュ済みワールドステート取得 |
| `GET` | `/api/relics?item=:name` | 特定アイテムをドロップするレリック検索 |
| `GET` | `/api/vaulted` | 現在Vault入りしているPrimeアイテム一覧 |
| `POST` | `/api/ordis/chat` | セファロンAIとの対話エンドポイント |
| `WS` | `/socket.io` | ロビー管理、部屋一覧、入退室同期、チャット |

## 6. 動作環境・セットアップ手順

### 前提要件
* Node.js 18.0.0 以上
* npm 9.0.0 以上

### コマンド
```bash
# 依存関係インストール
npm install

# 開発サーバー起動（Vite: 5173 / Server: 3001）
npm run dev

# プロダクションビルド
npm run build
```
