# 猫のアニメーション開発に関する総合レポート

## 1. 発生していた問題とその原因

### なぜ「寝ている姿」はできて、「活動している姿」はできなかったのか？
- **寝ている姿（sleep）が上手くいっていた理由**:
  元々手描きで作られたベース画像（`cat_sleep.png`）が存在し、着色プログラム（`natural_cat_generator.py`）もその座標（「このピクセルが目」「ここがお腹」）に精密に合わせて作られていたためです。
- **活動している姿（dash, play等）が失敗していた理由**:
  活動中の姿には元画像がなかったため、AIで新しく生成しました。しかし、AI生成の猫はちびキャラ（Chibi）風で元の手描き猫と頭身・形状が異なっていました。それを従来の座標固定型着色プログラムに無理やり通した結果、「目があるはずの場所にお腹がある」というズレが起き、体の横に巨大な目が描かれたり四角い白枠ノイズが残るバケモノ状態になっていました。

### なぜデバッグ画面（debug_viewer.py）では正常に見えていたのか？
初期設定の猫が「白猫（white）」だったためです。白猫は全体を白く塗るだけなので座標のズレが目立たず綺麗に見えていましたが、本編（pomodoro.py）で15種類の猫が同時に出たことで黒猫や三毛猫のバケモノ化が露呈しました。

## 2. これまでに実施した修正・改善内容

### ① 新しい着色アルゴリズムの導入（`scripts/chibi_cat_generator.py`）
- 座標依存の描画を廃止し、「白色部分（ボディ）を検知してベースカラーに置換」「三毛・トラ柄・シャム等の特徴的な模様を自然な配置で合成」する専用アルゴリズムを新設しました。

### ② お座りポーズ（sit）のデザイン刷新
- ユーザー様ご提示の写真（窓辺で横向きにお座りし、ふわふわの胸毛と、前足元にくるんと巻きつくボリューム満点の尻尾）を元に、新しい専用ベース画像（`assets/base_sprites/cat_sit.png`）を制作・組み込みました。

### ③ 前後関係の描画（Yソート / 深度制御）
- 画面の下側（手前・Y座標大）にいる猫が、画面の上側（奥・Y座標小）にいる猫の上に自然に重なって表示されるよう、Canvas上のZオーダー制御（リアルタイムYソート）を実装しました。

### ④ 背景色の明度調整（50%ソフト化）
- お部屋の背景画像（`room_bg.jpg`）を白と50%ブレンドし、淡く明るいパステルトーンに調整しました。猫たちやUIがくっきりと見やすくなっています。

### ⑤ Web版へのスプライト同期
- ローカル版で生成した全スプライトをWeb版（`web/public/sprites/`）にも同期しました。

## 3. 🚨 次回開発時に必ず対応する重要課題（ToDo）

次回作業時は、以下の4点を最優先で改修・実装してください。

### 1. 3秒ごとの動作・位置切り替えサイクルの見直しと再実装
- **現状の課題**: まだ意図したテンポ（3秒ごとに位置が変わり、別の動作の絵が出る）で綺麗に切り替わっていない。
- **対応方針**: タイマーカウントの減衰ロジック、移動完了判定、ポーズ切り替えロジックを抜本的に整理し、確実に「3秒移動 ➔ 3秒別ポーズ ➔ 3秒移動」のリズムで動作するように再構築する。

### 2. プログラムによる画像の変形（歪み）処理の完全撤廃
- **現状の課題**: 活動中の一部のアクションで、プログラム側で回転（rotate）やリサイズ（resize）をかけて変形させている部分があり、見た目が不自然になっている。
- **対応方針**: プログラムによる無理な画像変形を一切廃止し、すべて専用のコマ画像（手描きまたはAIスプライトフレーム）による純粋なパラパラアニメーションに統一する。

### 3. 猫の同一柄（重複）の制限と状態維持
- **現状の課題**: 活動開始（タイマー開始）や中止（タイマー停止）のたびに画面内の猫の柄や色がランダムに変わってしまっている。
- **対応方針**:
  - **「同じ柄の猫は画面上に1匹のみ」**という制限を設ける。
  - タイマーの開始・停止で猫の個体情報（ID・毛柄・位置）を破棄・再生成せず、同じ猫がその場で起きて動き出すように管理する。

### 4. ローカルアプリ（Python/Tkinter）の起動速度の高速化
- **現状の課題**: アプリの起動が重く、立ち上がりに時間がかかる。
- **対応方針**: 全スプライトの事前ロード処理や初期化フローを軽量化し、起動時間を大幅に短縮する。

## 4. ファイル構成と役割一覧

| ファイルパス | 役割 |
| :--- | :--- |
| `assets/base_sprites/` | アニメーションの元となる白黒線画ベース画像群（`cat_sit.png`, `cat_dash_0.png`, `cat_groom.png` 等） |
| `scripts/chibi_cat_generator.py` | AI/Chibi形状画像用の高速・自然な毛柄着色ジェネレーター |
| `scripts/natural_cat_generator.py` | 各種モーションのポーズ合成・反転・アニメーションフレーム生成 |
| `regenerate_all.py` | 15種類すべての猫スプライトを一括再生成するスクリプト |
| `core/cat_ai.py` | 猫たちの自律移動、3秒アクションサイクル、家具・猫同士のインタラクションAI |
| `pomodoro.py` | メインデスクトップアプリ（Tkinter、Yソート、タイマー、描画ループ） |
| `web/` | Next.js / React によるWeb版ポモドーロアプリ |
