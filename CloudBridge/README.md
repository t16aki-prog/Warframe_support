# CloudBridge (OneDrive to Google Drive Safe Relayer)

ローカルPCの限られたストレージ容量を考慮し、OneDrive同期フォルダ（オンデマンドファイル対応）から指定された容量上限までファイルをダウンロード（ステージング）し、Google DriveへアップロードしてAPIからのIDやハッシュで整合性を検証できた場合のみ、ローカルファイルを削除して容量を解放する安全転送アプリケーションです。

---

## ✨ 主な特長

1. **ローカル容量安全ガード (Staging Buffer Guard)**:
   - 一時ステージングバッファの上限サイズ（デフォルト: 5GB）を厳格に順守。
   - PCディスク全体の最小空き容量ガード（デフォルト: 5GB）を下回らないよう自動監視。
   - 上限に達した場合はダウンロードを一時保留し、アップロードと検証を完了して容量を解放してから次のファイルを取得。
2. **多段階の整合性検証 (Strict Verification)**:
   - Google Drive APIレスポンスから `id`、`size`、`md5Checksum` を取得。
   - ローカルファイルのバイトサイズおよびMD5ハッシュ値と完全一致するか照合。
   - 検証に100%成功した場合のみローカル一時ファイルを削除。
3. **即時停止＆フェイルセーフ (Fail-Safe Emergency Stop)**:
   - 通信エラー、ハッシュ不一致、APIエラー等の異常検知時は即座に全処理を停止。
   - エラー時はローカルファイルを一切削除せず保持（原因究明用）。
   - UI上の「緊急即時停止」ボタンで即座に安全中断可能。
4. **OneDrive元ファイルの完全保護**:
   - 移行完了後もOneDrive側の元ファイルは削除・変更せず安全保持。
5. **洗練されたWebUI (Dashboard)**:
   - リアルタイム容量ゲージ（バッファ使用率、PCディスク空き容量、転送全体進捗）。
   - 転送キューモニター（状態バッジ、ID、ハッシュ値）。
   - リアルタイムログターミナル（自動追従、カラーコード、即時エラーアラート）。

## 🚀 起動方法

### 必要な環境
- Python 3.10以上
- 必須パッケージ（インストール済み）: `Flask`, `Flask-SocketIO`, `google-api-python-client`, `google-auth-oauthlib`, `psutil`

### アプリケーションの起動
```bash
python CloudBridge/main.py
```
ブラウザが自動的に開き、`http://127.0.0.1:5055` にダッシュボードが表示されます。

---

## 🛠️ 設定項目
ダッシュボード右上の歯車アイコン（設定ボタン）から以下を設定可能です：
- **OneDrive 同期フォルダパス**: PC上のOneDriveフォルダパス（「自動検出」ボタンで自動設定可能）
- **バッファ容量上限 (GB)**: ローカルに一時展開を許容する最大サイズ
- **最小ディスク空き容量ガード (GB)**: ディスク空き容量の下限ライン
- **Google Drive 宛先フォルダ名**: アップロード先のGoogle Driveフォルダ名
- **模擬実行モード (Dry Run)**: 実際のGoogle Drive転送を行わずに動作テストを行うモード
