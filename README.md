# TennoNavi (Warframe Support Tool)

> **TennoNavi** は、Warframeプレイヤーのための非公式・高機能ファンメイド総合支援Webアプリケーションです。  
> リアルタイムの星系環境監視、レリック＆アイテム逆引き、分隊マッチングロビー（通常マルチ＆氷河の縛り対応）、セファロンAI（Gemini / ローカルLLM）を統合しています。

## 🚀 主な機能

### 1. リアルタイム・ダッシュボード
- **オープンワールド環境サイクル**: 地球、エイドロンの草原（昼/夜）、オーブ峡谷（温暖/寒冷）、カンビオン隔離庫（Vome/Fass）のタイマーを即座に表示
- **Voidの亀裂（Fissures）**: リソ・メソ・ネオ・アクシス・レクイエム・オムニアのリアルタイムミッション一覧
- **特別任務＆ウィークリー**: 突入（Sortie）、アルコン討伐戦、鋼の道のり、ナイトウェーブ進捗

### 2. レリック・ドロップ＆ビルド探索
- **レリック逆引きマトリクス**: 欲しいパーツ名からドロップするレリック・入手場所・Vault状態を即座に照会
- **募集チャット自動生成**: コピペするだけでゲーム内リクルートチャットへ投稿可能な定型文ジェネレーター

### 3. 分隊マッチングロビー (Multiplayer)
- **通常マルチ（4人）**: 亀裂ラン、レリック開放、素材周回などのリアルタイム分隊募集
- **氷河の縛り (The Icebind)**: 6人動的分隊スロット、Warframe重複完全禁止判定、公式縛りルール完全準拠の作戦ボード

### 4. セファロン・オーディス AI
- **ハイブリッドLLM対応**: Google Gemini API（要APIキー入力）または ローカルLLM（Ollama `qwen2.5:7b`）による質問回答・ビルド提案
- **思考時間短縮キャッシュ**: よくある質問に対する即答クイックファクト機構を搭載

## 🛠️ 開発・ローカル実行手順

### 前提条件
- Node.js 18以上
- npm または pnpm

### セットアップ
```bash
# 1. リポジトリをクローン
git clone https://github.com/t16aki-prog/Warframe_support.git
cd Warframe_support

# 2. ディレクトリへ移動して依存関係をインストール
cd Warframe_spport
npm install

# 3. 環境変数ファイルの準備 (任意)
cp .env.example .env

# 4. 開発サーバーの起動 (Viteフロントエンド + Expressサーバー)
npm run dev
```

起動後、ブラウザで **`http://localhost:5173`** を開いてください。

## 🌐 Web公開・デプロイに関する設定

本アプリケーションを Vercel、Render、Railway 等にデプロイする場合、以下の環境変数を設定できます。

| 環境変数 | 説明 | デフォルト値 |
| :--- | :--- | :--- |
| `PORT` | バックエンドサーバーの待機ポート | `3001` |
| `ALLOWED_ORIGINS` | CORS許可オリジン（カンマ区切り、例: `https://your-domain.com`） | `*` (開発用) |
| `VITE_SERVER_URL` | クライアントから接続するバックエンドURL（HTTPS/WSS） | 自動検出 / ローカルフォールバック |
| `GEMINI_API_KEY` | セファロンAI用APIキー（画面上の設定タブからも入力可能） | 空（未設定） |
