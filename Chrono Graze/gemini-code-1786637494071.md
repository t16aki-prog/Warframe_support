# 『インクリメンタル × 手動STG』 要件定義兼基本設計書

## 1. プロジェクト概要
* **開発言語**: C++
* **推奨エンジン方針**: Unreal Engine（最小構成・軽量化ビルド）、または Godot Engine / Siv3D / Raylib 等の軽量環境
* **ジャンル**: 弾幕手動シューティング × インクリメンタル（数値インフレ ＋ 放置自動化）
* **ターゲット属性**: 
  * STGが得意な人（ジャスト回避によるアクション攻略）
  * STGが苦手な人（周回・放置・ビルド構築によるゴリ押し攻略）の両立

## 3. コアアクション ＆ ジャスト回避メカニクス

### 3.1 自機判定・構造
* **判定構造**: 
  * `Hitbox`（被弾判定・小）: 自機中心の自機コア。視認性確保のため発光表示。
  * `Graze Box`（かすり判定・大）: 被弾判定の外側に配置されたジャスト回避判定枠。
* **ビーム発射位置**: 自機コアから少し前方に離れた位置から発射（自機周辺の視界遮蔽を防ぐ）。

### 3.2 ジャスト回避（グレイズ）仕様
* **発動条件**: 敵弾が `Graze Box` に入り、`Hitbox` に接触しなかった場合（またはボスの突進回避時）。
* **効果**:
  1. **5秒間、ステージポイント獲得量が20倍**に増加。
  2. **無敵時間**の発動（永久進化の基礎時間 ＋ ステージ内強化による延長時間）。
* **演出**:
  * 画面全体をタイムスロー（例: 0.3倍速）。
  * 低く重いサウンドエフェクト（ピッチダウンSE）を再生。

---

## 4. バトル・ボスシステム ＆ 成長表現

### 4.1 攻撃・成長の視覚的表現
* **ダメージ数値**: 画面を数字で埋め尽くさないため**完全非表示**。
* **成長表現**:
  * 攻撃力UP ＝ **秒間発射数（弾幕密度）の増加**。
  * 一定段階クリア ＝ **銃口（マルチショット）の増設**（1口 $\rightarrow$ 2口 $\rightarrow$ 4口...）。見た目の直接的な変化で成長を体感させる。

### 4.2 ボス戦 ＆ 確定ダウン（救済）メカニクス
* **属性相性**: 各ボス固有の相性（特定ビームやドローンが有効など）を設定。
* **確定ダウン救済**:
  * 全ボス共通で低頻度（滅多に来ない）の**「突進攻撃モーション」**を所有。
  * 突進に対して**「ジャスト回避 ＋ 攻撃」**を成功させると、どんなビルドでもボスが**確定ダウン（大隙＆大ダメージチャンス）**する。

## 5. 強化・成長システム（2系統）

### 5.1 ステージ内強化（In-Run Upgrade）
* **特徴**: 毎周回（ゲームオーバー・クリア時問わず）**前回の割り振りを記憶・1クリック加減算・一括リセット**が可能。
* **強化項目**:
  * 銃口増設 / 連射速度UP / 攻撃力UP
  * ドローンの追加・配備（所持スロット枠内）
  * 武器ジャンル（タイプ）の切り替え・強化
  * 残機の追加 / 体力（HP）の強化
  * 必殺技（ボム）の機能強化（ゲージ獲得量/威力）
  * 最初から一段階強化スタート
  * 敵からのパワーアップアイテムドロップ率UP
  * ステージポイント獲得倍率UP
  * ジャスト回避時の無敵時間延長

### 5.2 永久進化（Prestige Tree）
* **特徴**: 永続的なメタ成長。レベルキャップ（上限）あり。特定ステージで手に入る**「ステージ限定ポイント（属性通貨）」**が必要。
* **強化項目**:
  * **ステージゴーストの数を増やす**（並列自動周回数UP）
  * **ゴーストの放置上限時間拡張**（放置ストック時間UP）
  * **初期ビームジャンルの解禁**
  * **必殺技要素のアンロック**（STG苦手な人向け救済機能）
  * **ドローンの最大装備スロット枠拡張**
  * **残機初期値の増加**
  * **ジャスト回避の基礎無敵時間付与**
  * **永久ポイント獲得倍率UP**

## 6. ステージゴースト ＆ 放置自動化システム

* **自動周回メカニクス**:
  1. ステージクリア時、最短クリアタイムが記録される。
  2. ゴーストが自動生成され、クリアタイム周期でバックグラウンド自動クリアを行う。
  3. **最小クリアタイム制限（キャップ）**を設け、火力インフレによる即時連打・バランス崩壊を防ぐ。
  4. タイム短縮成功時にゴーストの周回周期が更新される。
  5. ゴーストの数に応じて並列処理でポイントを生成する。
* **オフライン処理**:
  * アプリ起動時に**「オフライン復帰ダイジェスト」**を表示し、離脱中の獲得ポイントを一括付与。

---

## 7. UI / UX ＆ オンボーディング

* **数値表記**: アルファベット表記（`1.00K`, `1.00M`, `1.00B`, `1.00T`, `1.00aa`, `1.00ab` ...）を採用。
* **段階的システム解禁（オンボーディング）**:
  * Stage 1: 移動・攻撃・ジャスト回避のみのシンプル操作。
  * Stage 1 クリア: 「ステージ内強化」機能開放。
  * Stage 2 クリア: 「ステージゴースト」「永久進化」解禁。

using BigNumber = double; // インフレ数値用

// --- 永続データ ---

    std::string name;
    int current_level = 0;
    int max_level = 10;
    BigNumber base_cost = 100.0;
    double growth_rate = 1.8;
};

// --- ジャスト回避システム ---
class JustDodgeSystem {
private:
    float buff_timer = 0.0f;
    double point_multiplier = 1.0;
    const double BOOST_FACTOR = 20.0; // 20倍
    const float DURATION = 5.0f;     // 5秒間

public:
    void update(float dt) {
        if (buff_timer > 0.0f) {
            buff_timer -= dt;
            if (buff_timer <= 0.0f) {
                buff_timer = 0.0f;
                point_multiplier = 1.0;
            }
        }
    }

    void triggerGraze() {
        buff_timer = DURATION;
        point_multiplier = BOOST_FACTOR;
        // ※ここでタイムスロー＆ピッチダウンSE再生処理
    }

    double getPointMultiplier() const { return point_multiplier; }
    bool isTriggered() const { return buff_timer > 0.0f; }
};
